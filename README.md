# Digital-Wellbeing
A machine learning-based application that predicts digital well-being by analyzing screen time, social media usage, lifestyle and mental health indicators. It identifies potential concerns such as loneliness, FOMO, anxiety and low mood, providing personalized suggestions for healthier digital habits.

# Digital Well-being Prediction System 📱

## About the Project
The Digital Well-being Prediction System is a machine learning-based application designed to analyze how digital habits and social media usage may influence an individual's overall well-being.

Users enter information about their personal details, daily screen time, social media usage patterns, sleep duration, physical activity and mental health indicators. The system uses trained machine learning models to predict their overall digital well-being category.

## Key Features
- **Well-being Prediction:** Classifies users into Good, Moderate or At-risk categories.
- **Mental Health Analysis:** Evaluates indicators such as anxiety, low mood and mental health support requirements.
- **Social Behaviour Analysis:** Predicts loneliness, social comparison, self-esteem and Fear of Missing Out (FOMO).
- **Life Satisfaction Analysis:** Estimates the user's life satisfaction score.
- **Personalized Suggestions:** Provides recommendations based on users' digital habits and prediction results.
- **Interactive Interface:** Built using Streamlit for easy user interaction.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Machine Learning
- Pickle (for loading trained models)

## Objective
To create an interactive machine learning application that helps users understand their digital habits, identify potentially unhealthy patterns and make informed decisions towards maintaining a healthier relationship with technology.

## Disclaimer
This application provides machine learning-based estimates and general lifestyle suggestions. It is not a medical diagnostic tool and does not replace professional mental health advice.
